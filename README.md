# 🚀 Nexura - თანამედროვე, მინიმალისტური და პროფესიონალური Landing Page

Nexura არის მაღალი დონის, სრულად რესპონსიული და თანამედროვე ვებ-პლატფორმის სადესანტო გვერდი (Landing Page), რომელიც შექმნილია სუფთა **HTML5**, **CSS3** და **Vanilla JavaScript** ტექნოლოგიებით, ყოველგვარი ზედმეტი მძიმე ბიბლიოთეკების გარეშე.

პროექტი გამოირჩევა დახვეწილი მინიმალისტური ესთეტიკით, მიკრო-ანიმაციებით, მკაფიო ტიპოგრაფიითა და წარმოებისთვის მზა (Production-ready) სტრუქტურით.

## 🌟 ძირითადი მახასიათებლები და სექციები

### 1. 🧭 Header & Navigation (ჰედერი და ნავიგაცია)
- **ბრენდინგი და ლოგო:** Nexura-ს ვექტორული SVG ლოგო და სახელი.
- **დესკტოპ ნავიგაცია:** ჰორიზონტალური, სუფთა მენიუ გლუვი ხაზოვანი hover ეფექტით (`Home`, `About`, `Features`, `Contact`).
- **მობილური მენიუ (Hamburger Menu):** ანიმაციური ჰამბურგერ ღილაკი, რომელიც გარდაიქმნება 'X'-ად. მენიუ იხსნება გლუვი ანიმაციით და ავტომატურად იხურება ბმულზე დაკლიკებისას, გარე სივრცეში დაკლიკებისას ან `Escape` კლავიშზე დაჭერისას.
- **Smooth Scroll & ScrollSpy:** გვერდის გლუვი გადაადგილება შესაბამის სექციაზე, ჰედერის სიმაღლის გათვალისწინებით (`scroll-padding-top`) და მიმდინარე აქტიური სექციის ავტომატური გამოკვეთა ნავიგაციაში.
- **Dark / Light რეჟიმის გადამრთველი:** მუქ და ნათელ რეჟიმებს შორის მყისიერი გადართვა მომხმარებლის არჩევანის `localStorage`-ში შენახვით.

### 2. ⚡ Hero Section (მთავარი სექცია)
- **გამოკვეთილი ტიპოგრაფია:** დიდი, შთამბეჭდავი სათაური გრადიენტული აქცენტით.
- **მოკლე და მკაფიო აღწერა:** კომპანიის ღირებულებისა და უპირატესობის წარმოჩენა.
- **CTA ღილაკები:** მთავარი ღილაკი `Get Started` (დაიწყე ახლა) და მეორადი ღილაკი `Learn More` (გაიგე მეტი).
- **თანამედროვე ილუსტრაცია & Glassmorphism:** ინტერაქციული ციფრული დაფა (Live Analytics Dashboard), გრადიენტული SVG დიაგრამა და მოძრავი (Floating) სტატუს-ბარათები სისწრაფისა და უსაფრთხოების ინდიკატორებით.
- **სოციალური ნდობის ბლოკი:** 500+ პარტნიორის ინდიკატორი და 4.9/5 რეიტინგი.

### 3. ℹ️ About Section (ჩვენს შესახებ)
- **2-სვეტიანი განლაგება (Desktop):** ერთ მხარეს კომპანიის მიზანი, ფილოსოფია და ძირითადი უპირატესობები მარკირებული სიით; მეორე მხარეს – სტატისტიკური ბარათების ბადე.
- **1-სვეტიანი განლაგება (Mobile):** მობილურ ეკრანებზე ავტომატურად გადაეწყობა ერთ ვერტიკალურ სვეტად.
- **დინამიური სტატისტიკა (Count-Up Counters):** 4 მთავარი მეტრიკა (99.9% Uptime, 250+ პროექტი, 15x წარმადობა, 24/7 მხარდაჭერა), რომლებიც ეკრანზე გამოჩენისას (`IntersectionObserver`) ეფექტურად ითვლიან მნიშვნელობებს.

### 4. 💎 Features Section (ფუნქციები - 3 ბარათი)
- **3-სვეტიანი ბადე დესკტოპზე:** თითოეულ ბარათს აქვს უნიკალური გრადიენტული SVG აიქონი, სათაური, აღწერა და ინტერაქციული ბმული.
- **სრულად ადაპტირებადი მობილურზე:** მობილურ მოწყობილობებზე ავტომატურად ეწყობა 1 სვეტად.
- **Hover ეფექტები:** ბარათის აწევა (`translateY(-8px)`), აქცენტური ჩრდილი, რბილი ნათება და აიქონის მიკრო-როტაცია.
  1. *ელვისებური სისწრაფე*
  2. *უმაღლესი უსაფრთხოება*
  3. *მარტივი ინტეგრაცია*

### 5. 📬 Contact Section (კონტაქტი & ვალიდაცია)
- **ორმხრივი განლაგება:** ოფიციალური საკონტაქტო რეკვიზიტები (ელ.ფოსტა, ტელეფონი, ფიზიკური მისამართი) და საკონტაქტო ფორმა.
- **Client-Side ვალიდაცია (JavaScript):**
  - სახელის სისწორის შემოწმება (მინიმუმ 2 სიმბოლო);
  - ელ.ფოსტის ფორმატის ვალიდაცია რეგულარული გამოსახულებით (`Regex`);
  - თემისა და შეტყობინების სავალდებულოობა და სიგრძის კონტროლი;
  - შეცდომების ჩვენება თითოეული ველის ქვეშ რეალურ დროში და აკრეფისას გასუფთავება;
  - ხელმისაწვდომობის მხარდაჭერა (`aria-invalid`, `aria-describedby`).
- **Success Notification:** წარმატებული გაგზავნისას ღილაკზე ირთვება დატვირთვის სპინერი, რის შემდეგაც გამოდის ანიმაციური მწვანე წარმატების შეტყობინება და ფორმა სუფთავდება.

### 6. 🌐 Footer (ფუტერი)
- ბრენდის ლოგო და მოკლე აღწერა.
- სოციალური ქსელების ბმულები SVG აიქონებით (Twitter/X, LinkedIn, GitHub, Facebook) და hover ანიმაციებით.
- სტრუქტურირებული ნავიგაციის, სერვისებისა და რესურსების ბმულები.
- საავტორო უფლებები და სამართლებრივი ბმულები.
- მცურავი **Back to Top** ღილაკი გვერდის დასაწყისში ასასვლელად.

## 🛠️ ტექნოლოგიური სტეკი

- **HTML5:** სემანტიკური მარკირება (`header`, `nav`, `section`, `article`, `footer`), ოპტიმიზებული SEO მეტა-ტეგები.
- **CSS3:** 
  - CSS Custom Properties (თემების მართვისთვის: Dark/Light Mode);
  - Flexbox და CSS Grid განლაგება;
  - `clamp()` რესპონსიული ტიპოგრაფიისთვის;
  - Glassmorphism ეფექტები (`backdrop-filter`);
  - გლუვი ტრანზიციები და მიკრო-ანიმაციები.
- **JavaScript (ES6+):** 
  - DOM მანიპულაცია;
  - `IntersectionObserver` API სტატისტიკის ანიმაციისთვის;
  - ფორმის მონაცემების ვალიდაცია და მომხმარებლის ინტერაქცია;
  - `localStorage` API არჩეული თემის შესანახად.
- **ტიპოგრაფია:** Google Fonts: `FiraGO` (ქართული ტექსტებისთვის) და `Plus Jakarta Sans` (ლათინური ტექსტებისა და ციფრებისთვის).
